## What it does

`main.py` writes a single line — at most 200 characters — about a small
good thing that happened today, to `/output/entry.txt`.

> This morning the bus driver held the doors while I hopped up with one
> shoe untied, then grinned like my sprint had made his whole day.

A stranger's patience, returned as a shared little victory: warmth in
the held doors, surprise in the driver's grin, one concrete detail (the
untied shoe) to anchor it.

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $ENTRY_OUT/entry.txt when ENTRY_OUT is set)
```
